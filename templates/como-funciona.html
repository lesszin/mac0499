Como funciona

Como funciona a plataforma?

Explore os dados educacionais de forma simples, visualizando escolas, divisões administrativas, evolução temporal e relações espaciais.

Encontre uma escola

Comece pelo mapa para localizar uma escola e consultar suas informações. Utilize a busca ou os filtros disponíveis para encontrar instituições de acordo com diferentes características.

Busca

Pesquise uma escola pelo nome ou utilize o código da instituição para localizá-la diretamente no mapa.

Filtros

Refine os resultados utilizando informações como dependência administrativa, localização e modalidades de ensino.

Mapa

Visualize a distribuição das escolas geograficamente e explore diferentes regiões diretamente pelo mapa.

Explore uma divisão administrativa

Além da análise individual de escolas, a plataforma permite explorar os dados de diferentes níveis administrativos.

1

Brasil

Visualize as informações de todo o país.

2

Região

Explore uma das regiões brasileiras.

3

Estado

Analise os dados de uma unidade federativa.

4

Município

Consulte as escolas e indicadores de um município específico.

Consulte a ficha da escola

Ao selecionar uma escola, você pode acessar uma ficha com informações organizadas em diferentes categorias.

Matrículas

Consulte informações sobre matrículas, modalidades e distribuição dos estudantes.

Docentes

Explore informações relacionadas aos profissionais que atuam na escola.

Turmas

Visualize a distribuição das turmas e suas diferentes modalidades de ensino.

Estrutura

Consulte informações sobre infraestrutura, acessibilidade, tecnologia e materiais.

Analise a evolução ao longo do tempo

Os dados podem ser analisados historicamente para acompanhar mudanças nos indicadores educacionais de uma escola ou divisão administrativa.

Evolução temporal

Observe como os indicadores se comportam ao longo dos anos, identificando crescimento, redução e mudanças na composição dos dados.

Sobre os gráficos

Algumas das visualizações apresentadas na plataforma são disponibilizadas por meio de uma ferramenta externa de visualização de dados.

Gráficos e visualizações

Os gráficos são apresentados com o auxílio do Metabase. Por isso, ocasionalmente uma visualização pode levar mais tempo para carregar ou não aparecer imediatamente. Caso isso aconteça, recarregar a página pode fazer com que o gráfico seja carregado normalmente.

Compare diferentes contextos

Utilize as ferramentas de comparação para observar diferenças entre escolas, municípios e outros contextos educacionais.

Comparação

Coloque diferentes contextos lado a lado para facilitar a interpretação dos indicadores apresentados pela plataforma.

Analise espacialmente

O mapa também pode ser utilizado para observar a distribuição espacial das escolas e identificar padrões relacionados à localização.

Distribuição

Observe onde as escolas estão localizadas dentro de um determinado território.

Contexto espacial

Relacione a localização das escolas com diferentes divisões administrativas.

Jornada de exploração

A plataforma foi organizada para permitir uma exploração progressiva dos dados.
